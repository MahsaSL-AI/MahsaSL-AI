My work sits at the intersection of agentic systems, retrieval-augmented generation, backend engineering, and intelligent automation. I care about clear system boundaries, human oversight, security, observability, and graceful failure when AI meets the real world.

- Building agentic systems with tool use, validation, and bounded decision loops
